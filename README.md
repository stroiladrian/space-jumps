# Space Jumps

A one-tap endless jumper that runs in the browser. Tap, click or press Space to jump, climb as high as you can, and avoid the colour-shifting obstacles.

## Play

Open `index.html` in any modern browser. It is a single self-contained file (graphics, physics and sounds are all inside it), so there is nothing to install or build.

## Controls

- Tap / click / Space / Up arrow: jump
- Gear button (on the start screen): sound on/off
- High score and mute setting are saved in your browser
